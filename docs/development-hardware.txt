Packages deliberately deferred
  Audio development backends such as libasound2-dev, libpulse-dev, and
  libpipewire-0.3-dev are deferred until the audio milestone. Direct KMS/DRM/GBM,
  OpenGL/GLES, less common audio backends, RenderDoc, LLDB, ccache, mold, Neovim,
  and evtest are not required to draw the first triangle. Add them only when a
  milestone or diagnostic need justifies them.

  This package set is a project-specific minimum inferred from the official SDL
  all-features list and the first milestone's needs. During Step 3, inspect SDL's
  CMake feature summary. Wayland, X11, udev/USB, and the Vulkan GPU path must be
  present; optional omitted backends should be understood rather than ignored.

Step 3 scaffold verification
  A temporary GCC 13 / Unix Makefiles build was used before host package
  installation. It built pinned SDL statically, compiled both HLSL shaders to
  valid SPIR-V, linked the bootstrap executable without a dynamic SDL dependency,
  and ran the executable successfully. SDL's normal desktop configuration also
  correctly refused to configure while Wayland/X11 development support was
  incomplete.

  After installing the selected package baseline, the real development preset
  configured and built successfully with Clang 18.1.3 and Ninja 1.11.1. SDL was
  compiled statically with Wayland, X11, Vulkan/SDL_GPU, Linux haptics, HIDAPI,
  udev, and USB controller support. Both HLSL bootstrap shaders compiled to valid
  SPIR-V binaries, the executable linked without a dynamic SDL dependency, and
  the bootstrap executable ran successfully. clang-format and clang-tidy checks
  also passed for the current game source.

  The Wayland protocol generator emitted non-fatal DTD validation warnings for
  newer `deprecated-since` attributes. Generation and compilation still
  completed. Audio-backend development libraries remain deliberately deferred,
  so SDL's configuration warnings for ALSA, PipeWire, and PulseAudio are expected
  until the audio milestone.
